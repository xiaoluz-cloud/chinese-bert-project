# Classifying Chinese Text Difficulty for L2 Learners Using Fine-Tuned BERT

**STATS 507 Final Project** | Xiaolu Zheng | University of Michigan

## Overview

This project fine-tunes [`bert-base-chinese`](https://huggingface.co/bert-base-chinese) to classify Chinese sentences into four HSK difficulty levels (HSK 1–4), with the goal of supporting automatic readability assessment for Chinese as a second language (CSL) learners. A TF-IDF + Logistic Regression baseline is trained for comparison.

## Dataset

[`swaption2009/20k-en-zh-translation-pinyin-hsk`](https://huggingface.co/datasets/swaption2009/20k-en-zh-translation-pinyin-hsk) from Hugging Face — 22,364 Chinese sentences labeled with HSK difficulty levels 1 through 4.

| HSK Level | Sentences | Percentage |
|-----------|-----------|------------|
| HSK 1 | 2,695 | 12.1% |
| HSK 2 | 5,642 | 25.2% |
| HSK 3 | 5,810 | 26.0% |
| HSK 4 | 8,217 | 36.7% |

## How to Reproduce

### Requirements

```
datasets
transformers
torch
scikit-learn
pandas
matplotlib
seaborn
```

### Steps

1. **Open in Google Colab** (recommended)
   - Upload `notebooks/main.ipynb` to Google Colab
   - Go to **Runtime → Change runtime type → T4 GPU**

2. **Run all cells**
   - Runtime → Run all
   - Total runtime: ~30–45 minutes on T4 GPU

3. **Download figures**
   - All output figures are saved to the `figures/` folder
   - Use them directly in the IEEE report

### Local Setup (alternative)

```bash
git clone https://github.com/YOUR_USERNAME/chinese-bert-project.git
cd chinese-bert-project
pip install -r requirements.txt
jupyter notebook notebooks/main.ipynb
```

> **Note:** A GPU is strongly recommended. CPU-only training will be significantly slower.
